# Disk Scanner

免费的大文件扫描工具，帮你找出硬盘空间杀手。

**纯浏览器本地运行，不会上传任何文件。**

## 使用方法

1. 打开 [Disk Scanner](https://zzz123123lll.github.io/disk-scanner/)
2. 点击选择文件夹，或直接拖拽文件夹到页面
3. 自动扫描并显示最大的文件

## 特点

- 完全离线可用（下载 HTML 双击即用）
- 不上传文件，隐私安全
- 空间占比饼图
- 一键复制大文件列表
- 导出 CSV 报表
- 可视化排行榜，一眼看出谁在吃空间

## 技术

纯 HTML/CSS/JS，零依赖，单文件。
